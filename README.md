# 录入审定信息

基于 Pencil V2 设计稿实现的工程业务审定信息录入演示网站。

## 页面范围

- 送审信息
- 结算总审定
- 施工费审定（合同1、合同2）
- 设计费审定
- 监理费审定
- 甲供材料
- 甲供设备
- 其他费用审定
- 拆旧物资
- 结算

## 功能

- 两级业务导航与选中状态
- 输入文本、数值、日期、金额步进、只读预览五类字段
- 金额上下调整、保存反馈与取消恢复
- 桌面端右侧工作抽屉和移动端业务导航
- GitHub Pages 自动部署

## 本地运行

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
```
