# 工程审计业务系统

基于 Pencil 最终版设计稿实现的工程审计业务演示系统，包含送审管理完整页面与录入审定信息抽屉。

演示地址：https://yih14601-wq.github.io/engineering-review-entry-demo/

## 页面范围

- 送审管理：项目资料、施工、设计、监理、甲供物资、其他信息、附件上传列表
- 录入审定信息：送审信息与 9 个审定信息分类同页纵向长表单

## 核心功能

- 两个页面均使用左侧锚点导航控制内容区平滑滚动和滚动高亮
- 施工、设计、监理支持字段组新增和删除
- 施工至少保留 1 个字段组，最后一组删除操作自动锁定
- 设计与监理允许删除到 0 组，并通过空状态重新新增
- 新增供应商通过独立弹窗写入数据库，不在当前表单追加字段
- 附件上传支持一次多选、分批重复上传和单文件移除
- 输入文本、数值、日期、金额步进、下拉选择和只读预览字段
- 1920×1080 桌面布局按 Pencil 设计尺寸复刻，并适配常规桌面与移动端

## 本地运行

```bash
pnpm install
pnpm dev
```

生产检查：

```bash
pnpm typecheck
pnpm build
```

`main` 分支更新后，GitHub Actions 会自动构建并部署到 GitHub Pages。
