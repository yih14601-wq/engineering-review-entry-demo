# 验收清单

## 基础运行

- [ ] 页面可在原 Vue 系统中打开。
- [ ] 不依赖 React 或 React DOM。
- [ ] 1920x1080 下布局与 Pencil 基本一致。
- [ ] 常规桌面宽度和移动端无横向滚动条。
- [ ] 控制台无明显报错。

## 送审管理

- [ ] 顶部和左侧白色占位区域没有业务数据。
- [ ] 顶部左上角有 `审计计划` 和 `录入审定信息` 按钮。
- [ ] 工单内容是上下滚动，不是分页。
- [ ] `送审资料：1` 跟随内容滚动，不固定。
- [ ] 底部固定操作栏包含 `不提交，仅保存`、`保存并提交`。
- [ ] 施工默认至少 1 组，最后 1 组不可删除。
- [ ] 设计和监理可删除到 0。
- [ ] 设计/监理空状态文案没有“字段组”三个字。
- [ ] 新增供应商弹窗可打开、校验空值、提交后提示。

## 录入审定信息

- [ ] 点击按钮打开右侧抽屉。
- [ ] 抽屉标题为 `录入审定信息`。
- [ ] 送审信息和审定信息在同一长页面内。
- [ ] 左侧导航点击能滚动到对应分类。
- [ ] 内容滚动时左侧导航同步高亮。
- [ ] 施工费审定包含合同 1 和合同 2。
- [ ] 合同 1 和合同 2 之间有分割线。
- [ ] 底部固定操作栏包含 `取消`、`保存`。

## 审计计划

- [ ] 页面标题为 `审计计划`。
- [ ] 布局与送审管理一致。
- [ ] 工单顶部显示 `工程详情` 和 `当前项目：1`。
- [ ] `当前流程节点` 是按钮样式。
- [ ] 全部字段为只读预览。
- [ ] 所有附件展示字段默认 4 份文件。
- [ ] 定案单类型为 5 个 Tab，不是下拉。
- [ ] 定案单扫描件点击可放大查看。
- [ ] 左侧目录项较多时，高亮项会自动滚动到可视区域。

## 附件上传

- [ ] 空状态显示拖拽上传区域和 `选择文件` 按钮。
- [ ] 支持一次多选。
- [ ] 支持分批继续上传。
- [ ] 上传成功后变为紧凑文件列表。
- [ ] 文件行显示文件名、大小、成功 icon、删除 icon。
- [ ] 超过 50MB 的文件显示失败状态。
- [ ] 失败文件显示重试和删除。
- [ ] 删除最后一个文件后回到空状态。

## 视觉

- [ ] 一级标题使用蓝底方块 icon。
- [ ] 二级标题 icon 为 32x32。
- [ ] 三级合同 icon 为 28x28，绿色系。
- [ ] 标题本身没有底色框。
- [ ] 左侧导航选中态圆角为 0。
- [ ] 输入文本和数值字段内没有多余 icon。
- [ ] 只读/禁用状态不显示文字，用视觉状态和锁 icon 表示。
