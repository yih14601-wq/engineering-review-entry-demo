# 组件与交互规范

## 设计基调

系统是工程审计业务表单，视觉应克制、清晰、高密度、方便扫描。不要做营销感布局，不要增加大面积渐变、装饰背景或说明性大卡片。

## 布局

- 设计稿目标尺寸：`1920x1080`。
- 页面顶部白色区域高度参考 Demo。
- 左侧系统占位区域为空，不放业务数据。
- 右下工单卡片约 `1610x920px`，内部为左侧目录 + 右侧内容。
- 工单目录宽度约 `244px`。
- 内容区上下滚动，底部操作栏固定。
- 主要内容间距保持 `16px` 或 `24px` 级差，灰色卡片内边距统一。

## 左侧锚点导航

- 一级：icon + 文字，高度 `48px`。
- 二级：圆点 + 文字，高度 `40px`，比一级更深缩进。
- 无展开箭头。
- 选中态：
  - 浅蓝底：`#e8f3ff` 或 `#e8f1ff`
  - 左侧蓝色竖线：`3px`
  - 圆角全部为 `0`
  - 文字蓝色并加粗
- 滚动同步：
  - 内容滚动到某 section 后，目录 active item 必须切换。
  - 若 active item 在目录可视区外，目录自身自动滚动到该项。

## 标题层级

- 一级内容标题：蓝底方块 icon + 标题，图标容器视觉类似审计计划中的一级标题。
- 二级标题 icon：固定 `32x32px`。
- 三级合同标题 icon：固定 `28x28px`，绿色系。
- 标题本身不要放入底色框。

## 字段组件

字段类型：

- `text`：普通文本输入，不带 icon。
- `number`：数值输入，不带 icon。
- `date`：日期输入，可带日期 icon。
- `amount`：金额步进，带“元”和上下增减按钮。
- `readonly`：只读预览，使用锁 icon 表示，不显示“只读”或“禁用”文字。
- `select`：下拉选择，仅送审管理工单需要。

尺寸：

- 二级普通字段：约 `360x72px`。
- 三级合同字段：约 `340x72px`。
- 字段 label 在上，控件在下。
- 输入框高度保持稳定，不因内容或 hover 造成布局跳动。

## 附件上传组件

### 空状态

- 大边框上传区域。
- 中间上传 icon。
- 主文案：`拖拽文件到此处，或点击选择文件`。
- 辅助文案：`支持一次多选，也可分批重复上传`。
- 主按钮：`选择文件`。

### 已上传状态

使用紧凑文件列表，参考 Pencil `V4/送审管理/10附件上传-多文件成功`：

- 顶部浅灰横条：
  - 左侧上传 icon
  - 中间文案：`拖拽文件到此处，或继续选择文件`
  - 辅助文案：`支持一次多选，也可分批重复上传`
  - 右侧按钮：`继续上传`
- 摘要：
  - 全成功：`已上传 N 份`
  - 有失败：`N 份成功 · M 份失败`
  - 右侧：`单个文件最大 50MB`
- 文件行：
  - 文件 icon
  - 文件名
  - 文件大小或 `上传失败`
  - 成功/失败 icon
  - 失败时显示重试 icon
  - 删除 icon

上传规则：

- 支持一次多选。
- 支持分批重复上传。
- 支持删除单个文件。
- 单文件大于 `50MB` 标记为失败。
- 失败文件可点击重试；若仍超过 50MB，提示失败。

## 送审管理交互

- 顶部左上角有两个按钮：`审计计划`、`录入审定信息`。
- 底部固定操作栏：
  - `不提交，仅保存`
  - `保存并提交`
- 施工组：
  - 默认至少 1 组。
  - 当只剩 1 组时，删除按钮禁用。
- 设计/监理组：
  - 可删除到 0。
  - 空状态文案用用户能懂的话，例如：`暂无设计内容，可新增一组信息`、`暂无监理内容，可新增一组信息`。
  - 不出现“字段组”三个字。
- 新增供应商：
  - 打开弹窗。
  - 输入供应商名称。
  - 提交后提示写入数据库，不在当前页面新增字段。

## 录入审定信息交互

- 从按钮打开右侧抽屉。
- 抽屉内左侧导航和右侧内容同页滚动。
- 底部固定操作栏：
  - `取消`
  - `保存`
- 点击取消恢复到上次保存内容。
- 点击保存更新保存值并提示成功。
- 施工费审定下合同 1 和合同 2 之间保留分割线。

## 审计计划交互

- 顶部左上角显示 `审计计划`。
- 有返回 `送审管理` 按钮。
- 有 `录入审定信息` 按钮。
- 工单顶部 `工程详情 / 当前项目：1` 跟随内容滚动。
- `当前流程节点` 是按钮样式，但当前 Demo 不需要展开效果。
- 所有字段为只读预览。
- 附件默认每类展示 4 份。
- 附件点击提示预览。
- 定案单类型是 5 个 Tab，不是下拉。
- 定案单扫描件点击后放大预览。
